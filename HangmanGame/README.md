# Hangman Game

A simple text-based Hangman game made with Python for the CodeAlpha Python Programming task.

## How to play

- The program randomly selects one word from a list of five words.
- Enter one letter per turn to guess the hidden word.
- You can make up to six incorrect guesses.
- The game ends when you guess the word or use all six incorrect guesses.

## Requirements

- Python 3
- No extra libraries are needed. The `random` module is included with Python.

## How to run

Open a terminal in this folder and run:

```bash
python main.py
```

The game uses a list, random selection, strings, a while loop, and if-else conditions.
