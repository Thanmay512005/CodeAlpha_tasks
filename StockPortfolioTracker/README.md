# Stock Portfolio Tracker

A console-based stock portfolio calculator made with Python for the CodeAlpha Python Programming task.

## What it does

- Uses a hardcoded dictionary of sample stock prices.
- Accepts stock names and quantities from the user.
- Calculates the value of each holding and the total portfolio value.
- Allows the user to save the summary in a text file.

## Sample stock prices

| Stock | Sample price |
| --- | ---: |
| AAPL | $180 |
| TSLA | $250 |
| GOOGL | $140 |
| MSFT | $420 |
| AMZN | $190 |

These are fixed example values in the program, not live market prices.

## Requirements

- Python 3
- No extra libraries are needed.

## How to run

Open a terminal in this folder and run:

```bash
python main.py
```

Enter a stock symbol and its quantity when asked. Type `done` when you have finished entering stocks.
