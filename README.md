# CodeAlpha Python Programming Tasks

This repository contains the three Python projects completed for the CodeAlpha Python Programming tasks.

## Projects

### 1. Basic Chatbot
A simple rule-based chatbot that responds to a few predefined messages.

**Run:**
```bash
cd BasicChatbot
python main.py
```

### 2. Hangman Game
A console-based word guessing game with five predefined words and a maximum of six incorrect guesses.

**Run:**
```bash
cd HangmanGame
python main.py
```

### 3. Stock Portfolio Tracker
A console program that accepts stock symbols and quantities, calculates the total value using sample prices, and optionally saves a text summary.

**Run:**
```bash
cd StockPortfolioTracker
python main.py
```

## Requirements

- Python 3
- No third-party packages are required.

Each project has its own folder and README with instructions. The stock prices in the portfolio tracker are fixed sample values, not live market data.
